ng serve (http://localhost:4200/)

~ Django (backend)
-- first, activate virtual environment:
.\.venv\Scripts\Activate.ps1
-- python manage.py runserver (http://127/0/0:8000/)

-- slight change: (Django)
1. check Django's version
./mentorconnect-env/Scripts/python.exe -m django --version

2. run Django development server
./mentorconnect-env/Scripts/python.exe manage.py runserver

3. to install other packages
./mentorconnect-env/Scripts/python.exe -m pip install package-name

-- something to do with the requirements.txt file:
1. to generate the file - it holds info about packages, libraries and other tools your project needs to operate.
./mentorconnect-env/Scripts/python.exe -m pip freeze > requirements.txt
python -m pip install -r requirements.txt
